# Calendar badge assets

The planning calendar cycles through these four states when you tap a date.

| Stored mark | Badge | Spending counted |
| --- | --- | --- |
| `RED` | Crossed wallet (`img/calendar-no-spend.png`) | Zero |
| `TEAL` | Checked wallet (`img/calendar-planned.png`) | Entered amount only |
| `YELLOW` | Coin icon | Daily bills plus the entered amount |
| No mark | Date numeral | Default daily calculation |
