## State mapping

- RED / free: crossed wallet, no spending; daily bills excluded.
- TEAL / lite: checked wallet, only the entered amount; daily bills excluded.
- YELLOW / full: existing vector coin badge, daily bills plus the entered amount.
- No mark: plain date numeral.

Stored mark values and budget calculations are unchanged. The calendar cycles through these same four states.
